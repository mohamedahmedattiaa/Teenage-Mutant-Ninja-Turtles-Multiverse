## 🐢 Teenage-Mutant-Ninja-Turtles-Multiverse

A 2D Python game built with `pygame`, featuring multiverse action, NPC interaction, video cutscenes, and immersive sound effects.

---

## 🖥️ Step 1: Install Python

You must install **Python 3.10 or higher**:

* Download Python from the official site:
  👉 [https://www.python.org/downloads/](https://www.python.org/downloads/)

> ✅ During installation, **make sure to check the box** that says:
> `Add Python to PATH`.

---

## 📦 Step 2: Install PIP (if not already installed)

PIP usually comes with Python, but to confirm:

```bash
python --version
pip --version
```

If `pip` is not recognized, follow the guide:
👉 [https://pip.pypa.io/en/stable/installation/](https://pip.pypa.io/en/stable/installation/)

---

## 🔧 Step 3: Install Required Libraries

Once Python and pip are ready, install the required libraries by running:

```bash
pip install pygame
pip install pyzero
```

> ℹ️ You can also put them all in one line:
> `pip install pygame pyzero`

---

## 🚀 How to Run the Game

1. Download or clone the repository.
2. Open a terminal inside the project folder.
3. Run the game using:

```bash
python main.py
```

Or run it from any Python IDE like VSCode, PyCharm, Thonny, or IDLE.

* 🖼️ `assets` folders: contain game images, sprites, and UI elements

---

## 🔄 Common Issues

* 🔇 **No sound?** Check that your sound is not muted and all sound files are correctly placed.
* ❌ **Module not found?** Re-run:

  ```bash
  pip install pygame pyzero
  ```
* 🧊 **Crash on launch?** Make sure Python ≥ 3.10 is installed and the script is executed inside the correct directory.
